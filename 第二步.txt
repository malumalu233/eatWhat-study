## 二、表单字段设计与 UI 实现

在 `edit.vue` 中实现以下表单字段，全部采用温馨日系治愈风设计：

1. **菜名（必填）**
   - 输入框类型：单行文本输入
   - placeholder 提示："请输入菜名，如红烧肉"
   - 最大长度限制：50 字符
   - 样式：大圆角输入框（border-radius: 12rpx），浅灰边框，聚焦时暖橘杏高亮

2. **图片集（必填，多图上传）**
   - 支持最多上传 9 张图片
   - 使用 uni.chooseImage API 实现多图选择
   - 图片预览功能：点击可全屏查看
   - 删除功能：每张图片右上角显示删除按钮
   - 上传进度指示器：上传过程中显示加载动画
   - 占位图：使用手绘简笔风格线性插画（可复用已有 `LineArt` 组件）

3. **制作步骤（详细文字描述，必填）**
   - 输入框类型：多行文本域（textarea）
   - 行数：6 行，支持自动扩展
   - placeholder 提示："请详细描述制作步骤，例如：1. 准备食材... 2. 热锅凉油..."
   - 样式：大圆角文本域，浅灰背景，宽松行间距

4. **类型分类（默认值 + 自定义）**
   - 输入框类型：单选标签组（Tag Selector）
   - 默认选项：硬菜、软菜、素菜、汤（以 pill-shaped 标签展示）
   - 支持管理员后续通过后台添加自定义类型（预留接口，当前版本固定这 4 个）
   - 选中状态：暖橘杏底色 + 深咖文字；未选中：浅灰底色 + 深灰文字

5. **减脂期可吃标识（布尔值开关）**
   - 输入框类型：Switch 开关组件
   - 开启状态：浅抹茶绿底色 + "✓ 减脂友好"
   - 关闭状态：浅灰底色 + "○ 非减脂"
   - 辅助说明文字："标注后可在减脂期筛选此菜品"

1. **数据库集合创建指导**
   - 在微信开发者工具中创建云开发环境（如尚未创建）

2. **云函数编写**
   - 创建云函数目录：`cloudfunctions/dish/`
   - 编写 `index.js`，实现以下方法：
     - `createDish(data)`：插入新菜品记录，自动附加 `_openid`（创建人）、`createTime`（创建时间戳）

     - `listDishes(filter?)`：查询菜品列表（支持按类型、减脂标识过滤，第二步暂返回全部）

3. **前端 API 封装**
   - 在 `src/api/dish.js` 中封装调用云函数的便捷方法

## 四、表单交互与校验逻辑

1. **表单验证规则**
   - 提交前检查所有必填字段是否已填写
   - 菜名不能为空且长度 ≤ 50
   - 图片集至少 1 张
   - 制作步骤可以为空
   - 类型必须选择一个
   - 验证失败时，在对应字段下方显示错误提示（红色文字，圆角小标签样式）

2. **提交流程**
   - 点击"保存"按钮后：
     1. 先校验表单完整性
     2. 若有图片，逐个上传至云存储，收集 `fileID`
     3. 调用云函数 `dish.createDish()` 保存完整数据
     4. 上传成功或失败后给予 Toast 提示
     5. 成功后关闭页面并返回首页

3. **加载状态管理**
   - 上传图片时显示全局 Loading 遮罩
   - 保存按钮在操作期间禁用并显示 loading 图标
   - 网络异常时捕获错误并提示"网络繁忙，请稍后重试"
